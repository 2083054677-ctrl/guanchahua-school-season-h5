# 观猹开学季｜出发吧！少年 · 高校活动 H5

观猹开学季的高校活动页，移动端优先的滚动长页。把 Figma 设计稿还原为可直接在微信内分发、分享的单页 H5。

在线预览：https://2083054677-ctrl.github.io/guanchahua-school-season-h5/

## 页面内容

- 首屏主视觉与小飞机动效
- 产品横向滑动卡片（产品集合）
- 共学营课程卡（AI PM / FDE / AI 漫剧 / 更多课程），带轻微摇摆动效
- 常见问题横向问答（两组问答卡片可左右滑动）
- 「观猹学社」介绍与课程入口
- 顶部阅读进度条，滚动时实时反馈

## 实现要点

- **单文件页面**：样式与交互全部内联在 `index.html`，不改动素材、不依赖构建工具，直接静态托管即可。
- **设计稿还原**：按 800 × 7969 的设计稿切图，页面容器等比例缩放；热点按钮用百分比定位（`left/top/width/height`），在任意屏宽下锚点不偏移。
- **交互**：产品卡与问答卡用 `overflow-x: auto` + `scroll-snap` 实现原生横向滑动；滚动、视口变化时重算卡片状态；键盘可聚焦，保留 `focus-visible` 焦点样式。
- **性能**：图片按展示尺寸导出并压缩，首屏优先加载主视觉，长页其余图片顺序加载。
